# Vimbisai Basvi — Personal Website

A luxury-editorial personal website for Vimbisai Basvi: engineer, educator, and builder.

## Stack

- Next.js 16 with the App Router
- React and TypeScript
- CSS design tokens and responsive layouts
- Bodoni Moda display typography
- Manrope interface/body typography
- Lucide icons
- Static content for the MVP

## Run locally

```bash
npm install
npm run dev
```

If the development server cannot inspect network interfaces in a restricted environment, use the production server:

```bash
npm run build
npm start -- -H 127.0.0.1
```
